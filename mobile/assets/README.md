# Assets Directory

This directory contains all the static assets for the MedChain Mobile app.

## Required Files

### App Icons
- `icon.png` - Main app icon (1024x1024)
- `adaptive-icon.png` - Android adaptive icon (1024x1024)
- `favicon.png` - Web favicon (32x32)

### Splash Screen
- `splash.png` - App launch screen (1242x2436)

### Notification
- `notification-icon.png` - Push notification icon (96x96)

## Icon Specifications

### App Icon (icon.png)
- **Size**: 1024x1024 pixels
- **Format**: PNG with transparency
- **Design**: MedChain logo with healthcare theme
- **Colors**: Primary blue (#2563eb) with white elements

### Adaptive Icon (adaptive-icon.png)
- **Size**: 1024x1024 pixels
- **Format**: PNG with transparency
- **Design**: Simplified version for Android adaptive icons
- **Safe Zone**: Keep important elements within 66% of the image

### Splash Screen (splash.png)
- **Size**: 1242x2436 pixels (iPhone X dimensions)
- **Format**: PNG
- **Background**: Primary blue (#2563eb)
- **Content**: MedChain logo and app name
- **Text**: "MedChain" in white, centered

## Design Guidelines

1. **Consistency**: Use the same color scheme across all assets
2. **Simplicity**: Keep designs clean and recognizable at small sizes
3. **Branding**: Maintain MedChain's healthcare and technology identity
4. **Accessibility**: Ensure good contrast and readability

## Placeholder Icons

Until custom icons are designed, you can use:
- Generic medical cross symbols
- Healthcare-related icons
- Technology/blockchain elements
- Professional, clean designs

## Tools for Creation

- **Figma**: Design and export
- **Adobe Illustrator**: Vector graphics
- **Sketch**: UI design
- **Online tools**: Canva, Figma, etc.

## File Naming Convention

- Use lowercase with hyphens
- Include dimensions in filename if needed
- Add version numbers for updates
- Example: `icon-v2-1024x1024.png`
